# KLE Blog Backend

Laravel 13, Filament v3 ve Sanctum tabanlı API. Tercih edilen çalışma şekli kök dizindeki `docker-compose.yml` dosyasıdır.

Yerel adresler (kök Compose ile): API http://localhost:8000/api, panel http://localhost:8000/admin.

Varsayılan admin: `admin@example.com` / `password`.

API sözleşmesi: `../docs/openapi.yaml` ve `../docs/kle-blog.postman_collection.json`.
